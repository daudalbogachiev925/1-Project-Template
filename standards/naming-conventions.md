# Соглашения об именовании 1С

## Префиксы
- Общие модули: без префикса (серверные), Клиент, ВызовСервера
- Расширения: префикс компании (например, ACME_)
- Справочники: без префикса, множественное число (Товары, Контрагенты)
- Документы: существительное единственного числа (ПоступлениеТоваров)

## Реквизиты
- Ссылочные: <Сущность> (например, Контрагент)
- Флаги: <Признак> (например, ЭтоГруппа, ПометкаУдаления)
- Даты: <Сущность><Событие> (например, ДатаНачала, ДатаОкончания)
- Суммы: <Сущность>Сумма (например, СуммаНДС)

## Функции
- Булевы: ИмяБулевое (ЭтоНовый, ЭтоГруппа, ЕстьОшибки)
- Геттеры: Получить<Что> (ПолучитьОстатки, ПолучитьКурс)
- Сеттеры: Установить<Что> (УстановитьСтатус)
- Проверки: Проверить<Что> (ПроверитьЗаполнение)
