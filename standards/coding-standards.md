# Стандарты кода 1С

## Общие правила
- Отступы: 4 пробела, без табов
- Кодировка: UTF-8 with BOM
- Длина строки: до 120 символов
- Файлы: расширение .bsl для модулей, .os для форм

## Именование
- Переменные: camelCase (например, количествоТоваров)
- Функции и процедуры: PascalCase (например, ПолучитьОстаткиТоваров)
- Общие модули: ОбщегоНазначения, РаботаСКурсамиВалют
- Формы: ФормаСпискаТовары, ФормаЭлементаКлиент

## Структура модуля
1. Объявление переменных
2. Экспортные процедуры и функции
3. Служебные процедуры и функции
4. Обработчики событий

## Обязательные директивы
- Все серверные процедуры: &НаСервере
- Клиентские обработчики: &НаКлиенте
- Компиляция: &НаСервереБезКонтекста для независимых методов

## Запрещено
- Магические числа (кроме 0 и 1)
- Жёсткие пути к файлам
- Выполнение запросов в цикле
- Тексты запросов в клиентском коде
- Соединение строк через +
